# DraconisDSA - Explanations

This directory contains beginner-friendly explanations of the data structures and algorithms implemented in this library. Each file covers:

- What the structure is and its purpose
- Implementation details specific to this codebase
- Operations with time complexity
- Pros, cons, and when to use
- A small example
